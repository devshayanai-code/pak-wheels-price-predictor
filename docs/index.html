How the estimate is made

The model learned how price changes with age, mileage, engine and brand from … listings, and was tested on … it never saw.

  1. You describe the car

    Make, model, year, engine, fuel, transmission, mileage and city. Inputs are checked before anything reaches the model.

  2. The model predicts

    A Gradient Boosting model, one of three algorithms compared with 5-fold cross-validation, predicts the price. It runs right here in your browser, so the answer is instant.

  3. You see the context

    A likely range that contained the real price for 8 in 10 cars the model never saw, plus real listings of the same car to compare.

Trained with scikit-learn in Python, then exported to model.json and run in JavaScript: no server needed. The repo also contains a Django REST API with POST /api/predict/.
