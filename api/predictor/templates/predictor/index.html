How it works

The listings were cleaned (duplicates, typos and impossible values removed), then Ridge regression, Random Forest and Gradient Boosting were compared with 5-fold cross-validation. The best model ({{ model_name }}) is served by a Django REST API: POST /api/predict/. The price range reflects the model's average error on cars it never saw during training.
